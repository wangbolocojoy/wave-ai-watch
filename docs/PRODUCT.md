# WAVE AI 智能手表 · 产品与技术方案

## 1. 硬件底座

来自 Waveshare 官方资料与板级 README：

- MCU：ESP32-S3R8，双核 240MHz，8MB PSRAM，32MB Flash
- 屏幕：2.06" 410×502 QSPI AMOLED，官方资料标注 CO5300 驱动
- 触摸：FT3168 电容触摸
- 电源：AXP2101 PMIC（电量、充电、升压/降压、屏幕供电）
- 运动：QMI8658 六轴 IMU（内置计步）
- 时钟：PCF85063 RTC
- 音频：ES7210 双数字麦克风 ADC + ES8311 音频 Codec
- 存储：TF 卡（本地音乐）
- 外壳：手表形态，圆角玻璃，侧边 BOOT/PWR 按键

## 2. 产品定位

不是“能跑语音助手的开发板”，而是一块能日常戴的 AI 手表：

1. **AI 优先**：抬腕/按键/唤醒词进入小智，语音对话、MCP 控制、实时字幕。
2. **手表优先**：时间、日期、电量、步数、通知，一眼可读；滑动切表盘/应用。
3. **本地优先**：时间、闹钟、计步、音乐尽量不依赖云端；断网仍可用。
4. **可维护**：配置中心、OTA、真机屏幕回读，改 UI 不需要反复盲刷。

| 模块 | 当前 | 目标 |
| --- | --- | --- |

## 5. 视觉方向

- 深色底 + 少量高亮色，不做大面积渐变/彩虹色。
- 一套卡片系统：圆角 20、1px 边框、低对比背景、图标 + 标题 + 数值。
- 表盘：三款差异化，不共用同一个“模板感”布局。
- 中文优先，字号层级 11/14/16/20/30/48。
- 动画只用于状态变化：页面进入、助手眼睛、进度环。

## 6. 里程碑

### P0 可用（当前优先）
- 修复真机截图颜色/实时屏幕。
- 设置页、活动页、应用页、表盘视觉统一。
- 真机验证：Wi-Fi、语音、亮度、表盘切换、配对。

### P1 日常可用
- PCF85063 RTC + 跨重启守时。
- 抬腕/按键唤醒、AOD、深度睡眠。
- 通知中心、天气、久坐提醒。
- 音乐播放页重构、封面/进度/队列。

### P2 产品化
- OTA、配置中心持久配对、日志/崩溃上报。
- 手机端通知桥接、表盘商店/自定义表盘。
- 功耗/续航实测与优化。

## 7. 已知风险

- 官方资料为 CO5300，当前固件使用 SH8601 初始化；显示可用，但颜色/刷新/低亮度行为仍需对比官方 BSP 后再迁移。
- `LV_USE_SNAPSHOT` 截图颜色已改为不交换 RGB565 字节；需真机复验。
- 真机字库 common 缺少“鎏”字形，当前显示名使用“金色雅韵”。
- 音频 AEC、麦克风阵列、SD 热插拔、QMI8658 计步准确性仍需真机长测。
